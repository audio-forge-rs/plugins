# Melody Maker - Quick Start

**Production-quality melody generator for alt-country/Americana**

Generates intelligent melodic phrases → outputs pure MIDI notes → direct to any instrument.

---

## 30-Second Setup

1. **Load Melody Maker** in track 1
2. **Load instrument** (Session Guitarist, Scarbee, etc.) in same track after Melody Maker
3. **Press play** - melody starts generating automatically
4. **Adjust parameters** to taste

Done! You're generating melodies.

---

## Multi-Track Sync (THE POWER FEATURE)

**All instances share the same key/mode/chord progression:**

```
Track 1: Melody Maker (Lead style) → Session Guitarist
Track 2: Melody Maker (Sparse style) → Scarbee Rick Bass  
Track 3: Melody Maker (Rhythmic style) → Ample Banjo
```

**All three tracks stay in the same key and follow the same chord progression!**

Just set different melody styles and variations - they all sync harmonically.

---

## Key Parameters

### Shared Across ALL Instances

- **Key** - C, D, E, F, G, A, B (+ flats/sharps)
- **Mode** - Major, Minor, Dorian, Mixolydian, Pentatonic
- **Progression** - I-IV-V-I, I-V-vi-IV, etc.

Change these in ANY instance and ALL instances update!

### Per-Instance (Different for Each Track)

- **Melody Style** - 9 types (Sparse, Melodic, Rhythmic, etc.)
- **Density** - How often notes play
- **Range** - How wide the melody spans
- **Variation** - Randomness amount
- **Phrase Length** - How long phrases are
- **Octave** - Output octave (2-6)

## 9 Melody Styles

### 1. Sparse & Lonesome
Minimal notes, long pauses, contemplative  
**Use:** Verses, atmospheric parts

### 2. Melodic & Flowing  
Stepwise motion, singing quality  
**Use:** Lead melodies, choruses

### 3. Rhythmic & Driving
Repeated notes, strong rhythm  
**Use:** Driving sections, grooves

### 4. Contemplative
Slow, minimal movement, meditative  
**Use:** Ballads, quiet moments

### 5. Pedal Steel Bends
Chromatic approaches, sliding motion  
**Use:** Country leads, emotional parts

### 6. Telecaster Twang
Bright, jumping intervals, energetic  
**Use:** Uptempo songs, hooks

### 7. Slide Guitar
Smooth glides, bluesy feel  
**Use:** Blues-influenced parts

### 8. Prairie Wind
Open, airy, sparse high notes  
**Use:** Atmospheric textures

### 9. Heartland Rock
Pentatonic, driving, classic rock feel  
**Use:** Anthemic choruses

## Chord Progressions

### I-IV-V-I (Classic)
C - F - G - C (in key of C)  
**Classic country/rock**

### I-V-vi-IV (Pop)
C - G - Am - F  
**Modern, radio-friendly**

### I-vi-IV-V
C - Am - F - G  
**50s progression, nostalgic**

### I-IV-I-V
C - F - C - G  
**Simple, driving**

### vi-IV-I-V (Sad)
Am - F - C - G  
**Minor feel, emotional**

### I-iii-IV-V
C - Em - F - G  
**Bright, uplifting**

  - Density: 60%
  - Range: 70%
  - Octave: 4

## Tips

### DO:
- ✅ Use multiple instances for arrangements
- ✅ Set melody style per instrument character
- ✅ Adjust density for each part's role
- ✅ Use octave parameter for proper range
- ✅ Change key/mode in ONE instance (all sync)

### DON'T:
- ❌ Set different keys in different instances (they'll override each other)
- ❌ Use same melody style on all tracks (boring!)
- ❌ Set density too high on all tracks (muddy)
- ❌ Forget to set proper octave for instrument

## Troubleshooting

**Q: Not hearing anything**  
A: Melody Maker outputs MIDI only. Load an instrument after it.

**Q: Multiple instances playing different keys**  
A: Expected! Key/mode/progression are shared. Last changed wins.  
Set key ONCE in any instance.

**Q: Melodies sound random/bad**  
A: Try different melody styles. Lower variation parameter.  
Some styles need lower density (30-50%).

**Q: All tracks playing same melody**  
A: Check melody style is different per track.  
Try different variation amounts.

**Q: Wrong octave for instrument**  
A: Adjust Octave parameter (2-6).  
Bass: 2-3, Guitar: 3-4, High parts: 4-5
