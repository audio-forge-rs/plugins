# Lonesome Picker - Quick Start

Get authentic alt-country banjo sounds in 30 seconds.

## Setup

### 1. In Bitwig Studio

Create this signal chain:
```
[MIDI Track] → [Lonesome Picker Plugin] → [Ample Ethno Banjo (Picking Mode)]
```

**IMPORTANT**: Set Ample Ethno Banjo to **Picking Mode**, not Strummer/Pattern mode.

### 2. Match Tempo

**Set "Tempo" in Lonesome Picker to match your project BPM** (e.g., 95 BPM)

### 3. Play Chords

- Play any chord or simple melody
- Lonesome Picker generates banjo picking
- You should hear authentic banjo!

## Common Setups

### 🌊 Sparse Atmospheric (Default Sound)

**Lonesome Picker Settings:**
```
Style: Sparse
Density: 30%
Drone: 70%
Sparseness: 70%
Tempo: [Match Project]
```

**How to use:**
- Hold chord or single note
- Banjo picks sparsely with drone
- Perfect for intros, ambient sections
- Lots of space and silence

## Parameter Cheat Sheet

| Parameter | What It Does | Sweet Spot |
|-----------|--------------|------------|
| Style | Picking pattern | Sparse or Clawhammer |
| Density | How many notes | 30-60% |
| Drone | 5th string (high G) | 50-70% |
| Melodic | Passing tones | 40-60% |
| Articulation | Hammer-ons, slides | 50-70% |
| Sparseness | Space between notes | 40-70% |
| Tempo | **MUST MATCH PROJECT** | Your BPM |
| Auto Transpose | Shift to banjo range | ON |

## Quick Tips

✅ **DO:**
- Start with Sparse style for atmospheric sound
- Use high Sparseness (60-80%) for alt-country
- Let the Drone parameter be 50-70%
- Match Tempo to your project
- Embrace silence and space

❌ **DON'T:**
- Use low Sparseness if you want atmosphere
- Expect rapid bluegrass rolls (wrong plugin)
- Forget to match Tempo
- Use without Auto Transpose (unless you know why)

## Troubleshooting

**No sound?**
- Check Ample Ethno Banjo is in Picking Mode (not Strummer)
- Verify Tempo is set correctly
- Make sure you're playing notes

**Too busy/bluegrassy?**
- Increase Sparseness to 70-90%
- Reduce Density to 20-40%
- Use Sparse style
- This is anti-bluegrass by design!

**Not enough drone?**
- Increase Drone parameter to 70-80%
- Use Sparse or Clawhammer style
- Drone adds that banjo character

**Wrong octave?**
- Check Auto Transpose is ON
- Plugin targets G3-D5 automatically

3. Embrace silence
4. Slower tempos
5. Space > notes
