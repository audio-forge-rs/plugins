# Low Rider - Quick Start

Transform guitar chords into compelling bass lines in 30 seconds.

## Setup

### 1. In Bitwig Studio

Create this signal chain:
```
[MIDI Track] → [Low Rider Plugin] → [Scarbee Rickenbacker Bass]
```

### 2. Match Tempo

**Set "Tempo" in Low Rider to match your project BPM** (e.g., 120 BPM)

### 3. Play Chords

- Play any chord progression on keyboard
- Low Rider generates bass line automatically
- You should hear bass!

## Common Setups

### 🎸 Alt-Country Driving Bass

**Low Rider Settings:**
```
Style: Driving
Activity: 60%
Syncopation: 40%
Movement: 50%
Articulation: 60%
Tempo: [Match Project]
```

**How to use:**
- Play chord progression
- Bass follows with syncopated rhythms
- Perfect for Son Volt/Wilco/Uncle Tupelo style

## Parameter Cheat Sheet

| Parameter | What It Does | Sweet Spot |
|-----------|--------------|------------|
| Style | Pattern type | Driving or Root-Fifth |
| Activity | How busy | 50-70% |
| Syncopation | Off-beat feel | 30-50% |
| Movement | Use of 5ths, passing tones | 40-60% |
| Articulation | Slides, mutes | 50-70% |
| Sustain | Note length | 60-80% |
| Tempo | **MUST MATCH PROJECT** | Your BPM |
| Octave | Bass register | Auto |

## Quick Troubleshooting

**No sound?**
- Check Tempo matches your project
- Verify Scarbee Rick is loaded and receiving MIDI
- Make sure you're playing chords/notes

**Too busy?**
- Reduce Activity to 30-40%
- Try "Roots" or "Sparse" style

**Too simple?**
- Increase Activity to 70-80%
- Try "Walking" or "Melodic" style
- Increase Movement to 60-80%

**Wrong octave?**
- Change Octave Preference (Lower/Auto/Higher)
- Auto works for most situations

Different feel, melodic interest
